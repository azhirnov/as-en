Install clang:

> sudo apt install clang

or with specified version:

> sudo apt install clang-16

Install libc++

> sudo apt install libc++-dev
> sudo apt install libc++abi-dev

or with specified version:

> sudo apt install libc++-16-dev
> sudo apt install libc++abi-16-dev

Test:

> clang-16 -v
> clang++-16 -v
