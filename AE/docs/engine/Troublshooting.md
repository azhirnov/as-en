
## failed FeatureSet::IsCompatible()

Engine use list of feature sets from ['shared_data/feature_set' folder](https://github.com/azhirnov/as-en/blob/dev/AE/engine/shared_data/feature_set).
All feature sets in this folder generated by [FeatureSetGen](https://github.com/azhirnov/as-en/blob/dev/AE/engine/tools/feature_set_gen/Readme.md).

In runtime engine create feature set for current graphics device in [`VDevice::InitFeatureSet()`](https://github.com/azhirnov/as-en/blob/dev/AE/engine/src/graphics_rhi/Vulkan/VDeviceFS.cpp).
Then predefined feature sets compared with current feature set in `FeatureSet::IsCompatible()`, so if this function returns `false` it indicated that feature set requires unsupported feature of format.

### How to check which feature is not supported

Replace `FeatureSet::IsCompatible()` by `DbgIsCompatible()` it will write to log first unsupported feature or list of unsupported formats.

### Old drivers problem

Folder [device_info](https://github.com/azhirnov/as-en/blob/dev/AE/engine/tools/device_info) contains JSON's with Vulkan 1.4.3xx, except mobile devices which can not update drivers.
For desktop platform you should update your graphics drivers.

Another way is add JSON with your current graphics driver features to the `device_info` folder, then run `FeatureSetGen` app and build `*.ResPack` target to recompile pipelines.


## failed `hash == FeatureSet::GetHashOfFS_Precalculated()`

Run `Tests.GraphicsRHI` target.
If `TEST( h == FeatureSet::GetHashOfFS_Precalculated() );` failed - copy new hash and paste it to `GetHashOfFS_Precalculated` function body in `FeatureSet.cpp.h`.

If `TEST( h == FeatureSet::GetHashOfFS_Precalculated() );` is not failed or after updating hash:
build `*.PackRes` target to recompile resources.
